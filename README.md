# nvim_config

This repository contains a custom configuration for [Neovim](https://neovim.io/), built entirely in Lua.

## Features

- **Fully Lua-based configuration**: Lightweight and fast.
- **Custom plugins**: Optimized for productivity and tailored workflows.
- **Extensible**: Easy to add or modify plugins and settings.
- **Keybindings**: Intuitive key mappings for an efficient editing experience.

## Requirements

- **Neovim**: Requires version 0.8+.
- **Git**: Needed for plugin management.
- **Node.js** (optional): For certain plugins requiring Node.js support.
